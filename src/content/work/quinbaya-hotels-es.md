description: |
  El objetivo de este proyecto es desarrollar una aplicación web usando Angular que permite a los usuarios buscar, reservar y gestionar habitaciones de hotel en la ciudad de Quimbaya. La aplicación proporciona una interfaz intuitiva y amigable para que los usuarios naveguen por diferentes hoteles, vean detalles de habitaciones disponibles, hagan reservas y gestionen sus reservas existentes.

problem: |
  Un proyecto de curso en el CESDE: construir una experiencia de reservas al estilo Airbnb — buscar, reservar y gestionar habitaciones de hotel — respaldada por una API real para operaciones CRUD sobre reservas. Desarrollado completamente en Angular con TypeScript para una mejor organización de componentes, con la guía de mi profesor Juan José Gallego.
